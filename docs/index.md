# Como Escrever Jogos para o ZX Spectrum
Bem-vindo ao guia definitivo sobre a mestria do **ZX Spectrum**.

Este volume foi concebido para guiar o leitor pelos arcanos do processador Z80 e pelas entranhas da icónica máquina da Sinclair. Deitando base nas fundações mais elementares até às rotinas cegas do motor de jogo, o desígnio é providenciar uma odisseia técnica para a criação autónoma de obras em puro código máquina.

## Ferramentas de Desenvolvimento

Para acompanhar as fintas práticas balizadas neste livro, usamos um arsenal moderno:
* **sjasmplus**: Um afamado compilador cruzado (*cross-assembler*) moderno e veloz para Z80 que corre diretamente na sua máquina atual e cria os ficheiros prontos para o Spectrum.
* **Fuse**: O emulador de referência, preciso e fiável, para testar a sua obra no imediato.
