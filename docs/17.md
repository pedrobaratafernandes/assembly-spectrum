# Capítulo Dezassete - Interrupções

Configurar as suas próprias interrupções pode ser um pesadelo da primeira vez que tenta, pois trata-se de um assunto complicado. Com a prática, torna-se um pouco mais fácil. Para fazer o Spectrum correr a nossa própria rotina de interrupção, temos de lhe indicar onde está a rotina, colocar a máquina no modo de interrupção 2 e garantir que as interrupções estão ativadas. Parece bastante simples, não é? A parte difícil é dizer ao Spectrum onde está localizada a nossa rotina.

Com a máquina no modo 2, o Z80 utiliza o registo `I` para determinar o byte alto do endereço do ponteiro para o endereço da rotina de serviço de interrupção. O byte baixo é fornecido pelo hardware. Na prática, nunca sabemos qual será o byte baixo – então, consegue ver o problema? O byte baixo pode ser 0, pode ser 255 ou pode estar em qualquer valor intermédio. Isto significa que precisamos de um bloco inteiro de 257 bytes composto por ponteiros para o endereço inicial da nossa rotina de serviço. Como o byte baixo fornecido pelo hardware pode ser ímpar ou par, temos de garantir que o byte baixo e o byte alto do endereço da nossa rotina de serviço sejam idênticos. Isto restringe seriamente os locais onde podemos colocar a nossa rotina. Também só devemos colocar a nossa tabela de ponteiros e a nossa rotina em RAM não contendida (*uncontended RAM*). Não os coloque abaixo do endereço 32768. Mesmo paginar um banco de RAM não contendido para esse fim, como o banco 1, produzirá problemas em certos modelos de Spectrum. Pessoalmente, considero o banco 0 um local tão bom como qualquer outro.

Digamos que escolhemos o endereço 51400 como a localização da nossa rotina de interrupção. Isto é válido porque tanto o byte alto como o byte baixo são 200, uma vez que 200 * 256 + 200 = 51400. Precisamos então de uma tabela de 129 ponteiros todos a apontar para este endereço, ou 257 instâncias de `defb 200`, localizadas no início de um limite de página de 256 bytes. Assumindo que a colocamos numa zona alta da memória para não estorvar, poderíamos iniciá-la em 254 * 256 = 65024. Faríamos isto:

```assembly
    EMPTYTAP "17_prog1.tap"

    ; --- BASIC loader ---
    ORG $5D00
BasicStart:
    db 0,10
    dw Line1End-Line1Start
Line1Start:
    db $fd, $b0, $22, "32767", $22, $0d
Line1End:
    db 0,20
    dw Line2End-Line2Start
Line2Start:
    db $ef, $22, $22, $af, $0d
Line2End:
    db 0,30
    dw Line3End-Line3Start
Line3Start:
    db $f9, $c0, $b0, $22, "32768", $22, $0d
Line3End:
BasicEnd:
    SAVETAP "17_prog1.tap", BASIC, "loader", BasicStart, BasicEnd-BasicStart, 10

    ORG 32768

    DEVICE ZXSPECTRUM48
    ORG $8000

start:
    org 51400
int:
    ; ... (rotina de serviço de interrupção)

    org 65024
    ; ponteiros para a rotina de interrupção.
    defb 200,200,200,200
    defb 200,200,200,200
    ; ...
    ; ...
    defb 200,200,200,200
    defb 200


    SAVESNA "17_prog1.sna", start
    SAVETAP "17_prog1.tap", CODE, "17_prog1", start, $ - start, start
```

Uf! De qualquer forma, chegamos agora à nossa rotina de interrupção. As interrupções podem ocorrer em qualquer momento, pelo que temos de preservar todos os registos que provavelmente iremos usar, executar o nosso código, opcionalmente chamar a rotina de serviço da ROM, restaurar os registos, reativar as interrupções e, finalmente, retornar da interrupção com um `reti`.

A nossa rotina poderá assemelhar-se a esta:

```assembly
    EMPTYTAP "17_prog2.tap"

    ; --- BASIC loader ---
    ORG $5D00
BasicStart:
    db 0,10
    dw Line1End-Line1Start
Line1Start:
    db $fd, $b0, $22, "32767", $22, $0d
Line1End:
    db 0,20
    dw Line2End-Line2Start
Line2Start:
    db $ef, $22, $22, $af, $0d
Line2End:
    db 0,30
    dw Line3End-Line3Start
Line3Start:
    db $f9, $c0, $b0, $22, "32768", $22, $0d
Line3End:
BasicEnd:
    SAVETAP "17_prog2.tap", BASIC, "loader", BasicStart, BasicEnd-BasicStart, 10

    ORG 32768

    DEVICE ZXSPECTRUM48
    ORG $8000

start:
int:
    push af
    push bc
    push hl
    push de
    push ix             ; preservar registos.
    call 49158          ; reproduzir música.
    rst 56              ; rotina da ROM, ler teclas e atualizar relógio.
    pop ix
    pop de
    pop hl
    pop bc
    pop af              ; restaurar registos.
    ei                  ; reativar sempre as interrupções antes de retornar.
    reti                ; concluído.
    ret


    SAVESNA "17_prog2.sna", start
    SAVETAP "17_prog2.tap", CODE, "17_prog2", start, $ - start, start
```

Se não estiver a ler o teclado através das variáveis do sistema, poderá dispensar o `rst 56`. Fazer isso libertará os registos `IY`. No entanto, se a sincronização do seu jogo contar os fotogramas utilizando o método descrito no capítulo sobre sincronização, precisará de incrementar o temporizador você mesmo:

```assembly
    EMPTYTAP "17_prog3.tap"

    ; --- BASIC loader ---
    ORG $5D00
BasicStart:
    db 0,10
    dw Line1End-Line1Start
Line1Start:
    db $fd, $b0, $22, "32767", $22, $0d
Line1End:
    db 0,20
    dw Line2End-Line2Start
Line2Start:
    db $ef, $22, $22, $af, $0d
Line2End:
    db 0,30
    dw Line3End-Line3Start
Line3Start:
    db $f9, $c0, $b0, $22, "32768", $22, $0d
Line3End:
BasicEnd:
    SAVETAP "17_prog3.tap", BASIC, "loader", BasicStart, BasicEnd-BasicStart, 10

    ORG 32768

    DEVICE ZXSPECTRUM48
    ORG $8000

start:
    ld hl,23672         ; contador de fotogramas.
    inc (hl)            ; incrementá-lo.


    SAVESNA "17_prog3.sna", start
    SAVETAP "17_prog3.tap", CODE, "17_prog3", start, $ - start, start
```

Com tudo isto preparado, estamos prontos para ativar as nossas interrupções. Temos de apontar o registo `I` para a tabela de ponteiros e selecionar o modo de interrupção 2. Este código fará o trabalho por nós:

```assembly
    EMPTYTAP "17_prog4.tap"

    ; --- BASIC loader ---
    ORG $5D00
BasicStart:
    db 0,10
    dw Line1End-Line1Start
Line1Start:
    db $fd, $b0, $22, "32767", $22, $0d
Line1End:
    db 0,20
    dw Line2End-Line2Start
Line2Start:
    db $ef, $22, $22, $af, $0d
Line2End:
    db 0,30
    dw Line3End-Line3Start
Line3Start:
    db $f9, $c0, $b0, $22, "32768", $22, $0d
Line3End:
BasicEnd:
    SAVETAP "17_prog4.tap", BASIC, "loader", BasicStart, BasicEnd-BasicStart, 10

    ORG 32768

    DEVICE ZXSPECTRUM48
    ORG $8000

start:
    di                  ; desativar interrupções por precaução.
    ld a,200            ; byte alto da localização da tabela de ponteiros (200*256 = 51200).
    ld i,a              ; definir byte alto.
    im 2                ; selecionar modo de interrupção 2.
    ei                  ; ativar interrupções.


    SAVESNA "17_prog4.sna", start
    SAVETAP "17_prog4.tap", CODE, "17_prog4", start, $ - start, start
```

## O Chamamento Imperativo e os Mecanismos Interrompidos

O avanço na rude finta da máquina baliza uma transação dita perante a valência da arquitetura no motor no embate aos apelidados saltos por finta ditada deitando no vulgar e estrito Modo de Interrupção 2 (fletido amarrado na batida letal mnemónica à `im 2`) que espelha num baluarte de finta decalcando contíguo na mestria o desígnio cravado por arremessar estrita no escrutínio o varrimento limpo ditado de fúria no arrastamento fletido e cego numa rota usurpada decalcando cinquenta exatos assaltos ditados contíguos deitando do fluxo amarrado ao chip perante o código afeto transigindo num segundo matriz! A cega finta da Interrupção deitando da matriz choca e amarra no processador um brutal sobressalto; a fúria da espicaçada deitada via hardware no cravado embate da placa de gráficos arrasta na submissa rotina a ditar uma imperativa ordem contígua paralisando cegos todos os escrutínios a correr e fletindo amarra matriz empurrando de imediato cego ao arranque deitando num calvário perante a afamada Subrotina de Serviço de Interrupção.

No limiar deitado balizando no vulgamente afamado Modo 1 transacionado perante o padrão a força decalcada do salto embate letal fletindo contíguo dita base ao engessado e imutável reduto cravado nas profundezas de finta em ROM num salto cego fixo à bitola de `$0038`. Mas no decalcado desígnio matriz fletido ao nosso apelidado Modo 2 batemos e impomos na rédea do CPU a ler decalcando amarra a um refúgio noutra morada estrita de salto cravando uma ramificação afeta a nós mesmos ditando um salto forçoso à nossa lide na estrita RAM! Para cimentar a manobra transigindo matriz perante esta finta o nosso chip funde o valioso e cego letal mastro do seu escasso registo matriz `I` de oito bits (servindo contíguo fletido para dita de parte alta no feixe originário cego) com as valências das poeiras dos bits arrastados decalcando perante as linhas cegas decalcadas pelo hardware no barramento (assumindo no cego escrutínio fletindo amarra à dita de metade deitada baia inferior) resultando num exato amarrar transacionando a porta rumo aos dezasseis bits no embate fletido cravando um resgatar atirando deitando o destino para a nossa interrupção!

A alavancagem desta máquina de guerra flete balizando deitando perante um ritual de transição cravado a exatas fintas nas mnemónicas; a fúria letal a silenciar fletida as ditas amarras com `di` (num esvaziar no transigir do cego e anglo-saxónico fletido a Disable Interrupts) resulta fletida fulcral a blindar transigindo a construção em RAM da nossa tabela fletida dos vetores, calando amarras e fintas letais que atirariam num embate cego originário o arrasto duma leitura avulsa cravando o CPU caso saltasse a meio arrastando o Spectrum para o inevitável silêncio do cego bloquear! A reativação emerge numa transição fletindo o `ei` (Enable Interrupts) transacionando o retorno decalcado; na derradeira saída e remate final da finta da nossa interrupção o retorno estrito em `reti` (num vulgar ditame do Return from Interrupt) dita na arquitetura fletindo do hardware cego o letal fechar decalcando na linha amarrada balizada base atestando o escoamento no livre percurso fletindo à espera para a transigida interrupção cravando noutra valência sucessiva. No decalcado assalto ao bailado cego o amarrar exige submisso na pureza do arranque matriz fletido fletir da salvação contígua ditando decalcando no varrimento contíguo da pilha todos e estritos registos avulsos cravando nas amarras a preservar na transação atirando aos vulgares `push` dita das matriz fletindo num amarrado `pop` ao encerramento sob risco deitante dum fatal trambolhão arrastando o nosso jogo perante um cruel falhanço do bloqueio na ruína fatal dos dados puros!
