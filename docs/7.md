# Capítulo Sete - Deteção Básica de Colisão de Alienígenas

## Verificação de Coordenadas

A verificação de coordenadas deverá ser autoexplicativa para a maioria dos programadores, mas é incluída aqui por uma questão de completude. É também o passo seguinte no desenvolvimento do nosso jogo Centipede.

O tipo mais simples de deteção de colisões seria algo assim, utilizado para detetar se dois UDGs colidiram:

```assembly
    DEVICE ZXSPECTRUM48
    ORG $8000

start:
    ld a,(playx)        ; coordenada x do jogador.
    cp (ix+1)           ; comparar com o x do alienígena.
    ret nz              ; diferente, logo não há colisão.
    ld a,(playy)        ; coordenada y do jogador.
    cp (ix+2)           ; comparar com o y do alienígena.
    ret nz              ; diferente, logo não há colisão.
    jp collis           ; temos uma colisão.


    SAVESNA "7_prog1.sna", start
    SAVETAP "7_prog1.tap", CODE, "7_prog1", start, $ - start, start
```

Tudo bem, isso é bastante simples, mas a maioria dos jogos não usa gráficos de caracteres de uma única célula. E se os alienígenas tiverem quatro células de largura por duas de altura, e o caráter do jogador tiver três quadrados de altura por três de largura? Precisamos de verificar se alguma parte do alienígena colidiu com alguma parte do jogador, pelo que temos de verificar se as coordenadas estão dentro de um determinado intervalo. Se o alienígena estiver a menos de dois quadrados acima do jogador, ou a menos de 3 abaixo dele, então as coordenadas verticais coincidem. Se o alienígena também estiver a menos de quatro quadrados à esquerda do jogador, e a menos de três quadrados à direita, então a posição horizontal também coincide e temos uma colisão.

Vamos escrever algum código para fazer isto. Podemos começar por obter a coordenada vertical do jogador:

```assembly
    DEVICE ZXSPECTRUM48
    ORG $8000

start:
    ld a,(playx)        ; coordenada x do jogador.


    SAVESNA "7_prog2.sna", start
    SAVETAP "7_prog2.tap", CODE, "7_prog2", start, $ - start, start
```

Depois, subtraímos a posição vertical do alienígena:

```assembly
    DEVICE ZXSPECTRUM48
    ORG $8000

start:
    sub (ix+1)          ; subtrair o x do alienígena.


    SAVESNA "7_prog3.sna", start
    SAVETAP "7_prog3.tap", CODE, "7_prog3", start, $ - start, start
```

A seguir, subtraímos um à altura do jogador (3 - 1 = 2) e adicionamo-lo:

```assembly
    DEVICE ZXSPECTRUM48
    ORG $8000

start:
    add a,2             ; o jogador tem 3 de altura, adicionamos 2.


    SAVESNA "7_prog4.sna", start
    SAVETAP "7_prog4.tap", CODE, "7_prog4", start, $ - start, start
```

Se o alienígena estiver dentro do intervalo, o resultado será menor do que a altura combinada do jogador e do alienígena, pelo que realizamos a verificação:

```assembly
    DEVICE ZXSPECTRUM48
    ORG $8000

start:
    cp 5                ; alturas combinadas são 3 + 2 = 5.
    ret nc              ; fora do intervalo vertical.


    SAVESNA "7_prog5.sna", start
    SAVETAP "7_prog5.tap", CODE, "7_prog5", start, $ - start, start
```

De forma semelhante, podemos prosseguir com o código para a verificação horizontal:

```assembly
    DEVICE ZXSPECTRUM48
    ORG $8000

start:
    ld a,(playy)        ; coordenada y do jogador.
    sub (ix+2)          ; subtrair o y do alienígena.
    add a,2             ; o jogador tem 3 de largura, adicionamos 2.
    cp 7                ; larguras combinadas são 3 + 4 = 7.
    ret nc              ; fora do intervalo horizontal.
    jp collis           ; temos uma colisão.


    SAVESNA "7_prog6.sna", start
    SAVETAP "7_prog6.tap", CODE, "7_prog6", start, $ - start, start
```

Claro que este método não funciona apenas para gráficos baseados em caracteres, também funciona perfeitamente com *sprites*, mas falaremos disso mais tarde. É altura de terminar o nosso jogo com alguma deteção de colisões. Como os nossos gráficos são todos UDGs de um único caráter, não precisamos de nada elaborado: basta uma verificação rápida de x=x e y=y.

```assembly
    DEVICE ZXSPECTRUM48
    ORG $8000

start:
    numseg: equ 8        ; número de segmentos da centopeia.

    ; Queremos um ecrã preto.
    ld a,71             ; tinta branca (7) em papel preto (0), brilho (64).
    ld (23693),a        ; definir as cores do nosso ecrã.
    xor a               ; forma rápida de carregar o acumulador com zero.
    call 8859           ; definir as cores permanentes da margem.

    ; Configurar os gráficos.
    ld hl,blocks        ; endereço dos dados dos gráficos definidos pelo utilizador.
    ld (23675),hl       ; fazer os UDGs apontarem para aí.

    ; Ok, vamos iniciar o jogo.
    call 3503           ; rotina da ROM que limpa o ecrã, abre o canal 2.

    xor a
    ld (dead),a         ; colocar acumulador a zero.
                    ; definir flag para indicar que jogador está vivo.

    ; Inicializar coordenadas.
    ld hl,21+15*256     ; carregar par hl com coordenadas iniciais.
    ld (plx),hl         ; definir as coordenadas do jogador.
    ld hl,255+255*256
    ld (pbx),hl         ; predefinição dos projéteis do jogador.
                    ; definir coordenadas dos projéteis.
    ld b,10             ; número de segmentos a inicializar.
    ld hl,segmnt        ; tabela de segmentos.
    segint: ld (hl),1    ; começar por mover para a direita.
    inc hl
    ld (hl),0           ; começar no topo.
    inc hl
    ld (hl),b           ; usar registo B como coordenada y.
    inc hl
    djnz segint         ; repetir até todos estarem inicializados.
    call basexy         ; definir as posições x e y do jogador.
    call splayr         ; mostrar símbolo da base do jogador.

    ; Agora queremos encher a área de jogo com cogumelos.
    ld a,68             ; tinta verde (4) em papel preto (0), brilho (64).
    ld (23695),a        ; definir as nossas cores temporárias.
    ld b,50             ; começar com alguns.
    mushlp: ld a,22      ; código de controlo para o caráter AT.
    rst 16
    call random         ; obter um número "aleatório".
    and 15              ; queremos a coordenada vertical no intervalo de 0 a 15.
    rst 16
    call random         ; obter outro número pseudoaleatório.
    and 31              ; queremos a coordenada horizontal no intervalo de 0 a 31.
    rst 16
    ld a,145            ; UDG 'B' é o gráfico do cogumelo.
    rst 16              ; colocar cogumelo no ecrã.
    djnz mushlp         ; ciclo de volta até que todos os cogumelos sejam mostrados.

    ; Este é o ciclo principal.
mloop:
    equ $

    ; Apagar o jogador.
    call basexy         ; definir as posições x e y do jogador.
    call wspace         ; mostrar espaço sobre o jogador.

    ; Agora que apagámos o jogador, podemos movê-lo antes de o voltar a mostrar
    ; nas suas novas coordenadas.
    ld bc,63486         ; linha do teclado 1-5 / porta do joystick 2.
    in a,(c)            ; ver que teclas estão pressionadas.
    rra                 ; bit mais exterior = tecla 1.
    push af             ; lembrar o valor.
    call nc,mpl         ; está a ser pressionada, mover para a esquerda.
    pop af              ; restaurar acumulador.
    rra                 ; próximo bit (valor 2) = tecla 2.
    push af             ; lembrar o valor.
    call nc,mpr         ; está a ser pressionada, mover para a direita.
    pop af              ; restaurar acumulador.
    rra                 ; próximo bit (valor 4) = tecla 3.
    push af             ; lembrar o valor.
    call nc,mpd         ; está a ser pressionada, mover para baixo.
    pop af              ; restaurar acumulador.
    rra                 ; próximo bit (valor 8) = tecla 4.
    push af             ; lembrar o valor.
    call nc,mpu         ; está a ser pressionada, mover para cima.
    pop af              ; restaurar acumulador.
    rra                 ; último bit (valor 16) lê a tecla 5.
    call nc,fire        ; está a ser pressionada, disparar.

    ; Agora que se moveu, podemos voltar a mostrar o jogador.
    call basexy         ; definir as posições x e y do jogador.
    call splayr         ; mostrar o jogador.

    ; Agora o projétil. Primeiro verificamos se atingiu alguma coisa.
    call bchk           ; verificar posição do projétil.
    call dbull          ; apagar projéteis.
    call moveb          ; mover projéteis.
    call bchk           ; verificar nova posição dos projéteis.
    call pbull          ; desenhar projéteis na nova posição.

    ; Agora os segmentos da centopeia.
    ld ix,segmnt        ; tabela de dados dos segmentos.
    ld b,10             ; número de segmentos na tabela.
    censeg: push bc
    ld a,(ix)           ; o segmento está ativo?
    inc a               ; 255=desligado, incrementa para zero.
    call nz,proseg      ; está ativo, processar segmento.
    pop bc
    ld de,3             ; 3 bytes por segmento.
    add ix,de           ; obter próximo segmento nos registos ix.
    djnz censeg         ; repetir para todos os segmentos.

    halt                ; atraso.

    ld a,(dead)
    and a
    ret nz              ; o jogador foi morto por um segmento?
                    ; jogador morto - perde uma vida.

    ; Saltar de volta para o início do ciclo principal.
    jp mloop

    ; Mover jogador para a esquerda.
mpl:
    ld hl,ply           ; lembre-se, y é a coordenada horizontal!
    ld a,(hl)           ; qual é o valor atual?
    and a               ; é zero?
    ret z               ; sim, não podemos ir mais para a esquerda.

    ; agora verificar se não há um cogumelo no caminho.
    ld bc,(plx)         ; coordenadas atuais.
    dec b               ; olhar 1 quadrado para a esquerda.
    call atadd          ; obter endereço do atributo nesta posição.
    cp 68               ; cogumelos são brilho (64) + verde (4).
    ret z               ; há um cogumelo - não nos podemos mover para lá.

    dec (hl)            ; subtrair 1 à coordenada y.
    ret

    ; Mover jogador para a direita.
mpr:
    ld hl,ply           ; lembre-se, y é a coordenada horizontal!
    ld a,(hl)           ; qual é o valor atual?
    cp 31               ; está na extremidade direita (31)?
    ret z               ; sim, não podemos ir mais para a direita.

    ; agora verificar se não há um cogumelo no caminho.
    ld bc,(plx)         ; coordenadas atuais.
    inc b               ; olhar 1 quadrado para a direita.
    call atadd          ; obter endereço do atributo nesta posição.
    cp 68               ; cogumelos são brilho (64) + verde (4).
    ret z               ; há um cogumelo - não nos podemos mover para lá.

    inc (hl)            ; adicionar 1 à coordenada y.
    ret

    ; Mover jogador para cima.
mpu:
    ld hl,plx           ; lembre-se, x é a coordenada vertical!
    ld a,(hl)           ; qual é o valor atual?
    cp 4                ; está no limite superior (4)?
    ret z               ; sim, não podemos ir mais para cima.

    ; agora verificar se não há um cogumelo no caminho.
    ld bc,(plx)         ; coordenadas atuais.
    dec c               ; olhar 1 quadrado para cima.
    call atadd          ; obter endereço do atributo nesta posição.
    cp 68               ; cogumelos são brilho (64) + verde (4).
    ret z               ; há um cogumelo - não nos podemos mover para lá.

    dec (hl)            ; subtrair 1 à coordenada x.
    ret

    ; Mover jogador para baixo.
mpd:
    ld hl,plx           ; lembre-se, x é a coordenada vertical!
    ld a,(hl)           ; qual é o valor atual?
    cp 21               ; já está no fundo (21)?
    ret z               ; sim, não podemos descer mais.

    ; agora verificar se não há um cogumelo no caminho.
    ld bc,(plx)         ; coordenadas atuais.
    inc c               ; olhar 1 quadrado para baixo.
    call atadd          ; obter endereço do atributo nesta posição.
    cp 68               ; cogumelos são brilho (64) + verde (4).
    ret z               ; há um cogumelo - não nos podemos mover para lá.

    inc (hl)            ; adicionar 1 à coordenada x.
    ret

    ; Disparar um míssil.
fire:
    ld a,(pbx)          ; coordenada vertical do projétil.
    inc a               ; 255 é o valor predefinido, incrementa para zero.
    ret nz              ; projétil no ecrã, não pode disparar novamente.
    ld hl,(plx)         ; coordenadas do jogador.
    dec l               ; 1 quadrado acima.
    ld (pbx),hl         ; definir coordenadas do projétil.
    ret

bchk:
    ld a,(pbx)          ; coordenada vertical do projétil.
    inc a               ; está em 255 (predefinido)?
    ret z               ; sim, não há projétil no ecrã.
    ld bc,(pbx)         ; obter coordenadas.
    call atadd          ; encontrar atributo nesta posição.
    cp 68               ; cogumelos são brilho (64) + verde (4).
    jr z,hmush          ; atingiu um cogumelo!
    ret

hmush:
    ld a,22             ; código de controlo AT.
    rst 16
    ld a,(pbx)          ; coordenada vertical do projétil.
    rst 16
    ld a,(pby)          ; coordenada horizontal do projétil.
    rst 16
    call wspace         ; apagar com espaço (tinta branca).
    kilbul: ld a,255     ; coordenada x de 255 = desativar projétil.
    ld (pbx),a          ; destruir projétil.
    ret

    ; Mover o projétil no ecrã uma posição de caráter de cada vez para cima.
moveb:
    ld a,(pbx)          ; coordenada vertical do projétil.
    inc a               ; está em 255 (predefinido)?
    ret z               ; sim, não há projétil no ecrã.
    sub 2               ; subir 1 linha (subtrair 2 pois a coord vertical está no byte alto do par).
    ld (pbx),a
    ret

    ; Configurar as coordenadas x e y para a posição da base/arma do jogador,
    ; esta rotina é chamada antes da visualização e eliminação da base.
    basexy: ld a,22      ; código AT.
    rst 16
    ld a,(plx)          ; coordenada vertical do jogador.
    rst 16              ; definir posição vertical do jogador.
    ld a,(ply)          ; posição horizontal do jogador.
    rst 16              ; definir a coordenada horizontal.
    ret

    ; Mostrar o jogador na posição de impressão atual.
    splayr: ld a,69      ; tinta ciano (5) no papel preto (0), brilho (64).
    ld (23695),a        ; definir as nossas cores de ecrã temporárias.
    ld a,144            ; código ASCII para UDG 'A'.
    rst 16              ; desenhar o jogador.
    ret

pbull:
    ld a,(pbx)          ; coordenada vertical do projétil.
    inc a               ; está em 255 (predefinido)?
    ret z               ; sim, não há projétil no ecrã.
    call bullxy         ; configurar coordenadas do projétil.
    ld a,16             ; caráter de controlo INK.
    rst 16
    ld a,6              ; 6 = amarelo.
    ld a,147            ; UDG 'D' é usado para os projéteis do jogador.
    rst 16
    ret

dbull:
    ld a,(pbx)          ; coordenada vertical do projétil.
    inc a               ; está em 255 (predefinido)?
    ret z               ; sim, não há projétil no ecrã.
    call bullxy         ; configurar coordenadas do projétil.
    wspace: ld a,71      ; tinta branca (7) no papel preto (0), brilho (64).
    ld (23695),a        ; definir as nossas cores de ecrã temporárias.
    ld a,32             ; caráter de ESPAÇO.
    rst 16              ; mostrar espaço.
    ret

    ; Configurar as coordenadas x e y para a posição do projétil do jogador,
    ; esta rotina é chamada antes da visualização e eliminação do projétil.
    bullxy: ld a,22      ; código AT.
    rst 16
    ld a,(pbx)          ; coordenada vertical do projétil.
    rst 16              ; definir posição vertical do jogador.
    ld a,(pby)          ; posição horizontal do projétil.
    rst 16              ; definir a coordenada horizontal.
    ret

    segxy: ld a,22       ; ASCII para caráter AT.
    rst 16              ; mostrar código AT.
    ld a,(ix+1)         ; obter coordenada x do segmento.
    rst 16              ; mostrar código de coordenada.
    ld a,(ix+2)         ; obter coordenada y do segmento.
    rst 16              ; mostrar código de coordenada.
    ret

    proseg: call segcol  ; deteção de colisão do segmento.
    ld a,(ix)           ; verificar se o segmento foi desligado
    inc a               ; pela rotina de deteção de colisões.
    ret z               ; estava desativado, logo o segmento está morto.
    call segxy          ; configurar coordenadas do segmento.
    call wspace         ; mostrar um espaço (tinta branca em papel preto).
    call segmov         ; mover segmento.
    call segcol         ; verificação de colisão na nova posição.
    ld a,(ix)           ; verificar se o segmento foi desligado
    inc a               ; pela rotina de deteção de colisões.
    ret z               ; estava desativado, logo o segmento está morto.
    call segxy          ; configurar coordenadas do segmento.
    ld a,2              ; código de atributo 2 = segmento vermelho.
    ld (23695),a        ; definir atributos temporários.
    ld a,146            ; UDG 'C' para mostrar o segmento.
    rst 16              ; desenhar segmento.
    ret

    segmov: ld a,(ix+1)  ; coordenada x.
    ld c,a              ; área GP x.
    ld a,(ix+2)         ; coordenada y.
    ld b,a              ; área GP y.
    ld a,(ix)           ; byte de estado.
    and a               ; o segmento está a ir para a esquerda?
    jr z,segml          ; a ir para a esquerda - saltar para essa secção.

    ; caso contrário, o segmento está a ir para a direita!
    segmr: ld a,(ix+2)   ; coordenada y.
    cp 31               ; já está no limite direito do ecrã?
    jr z,segmd          ; sim - mover segmento para baixo.
    inc a
    ld b,a              ; olhar para a direita.
    call atadd          ; obter endereço de atributo.
    cp 68               ; cogumelos são brilho (64) + verde (4).
    jr z,segmd          ; cogumelo à direita, mover para baixo.
    inc (ix+2)          ; sem obstáculos, mover para a direita.
    ret

    ; caso contrário, o segmento está a ir para a esquerda!
    segml: ld a,(ix+2)   ; coordenada y.
    and a               ; já está no limite esquerdo do ecrã?
    jr z,segmd          ; sim - mover segmento para baixo.
    dec a
    ld b,a              ; olhar para a esquerda.
    call atadd          ; obter endereço de atributo em (dispx,dispy).
    cp 68               ; cogumelos são brilho (64) + verde (4).
    jr z,segmd          ; cogumelo à esquerda, mover para baixo.
    dec (ix+2)          ; sem obstáculos, mover para a esquerda.
    ret

    ; caso contrário, o segmento está a ir para baixo!
    segmd: ld a,(ix)     ; direção do segmento.
    xor 1               ; inverter direção.
    ld (ix),a           ; guardar nova direção.
    ld a,(ix+1)         ; coordenada y.
    cp 21               ; já está no fundo do ecrã?
    jr z,segmt          ; sim - mover segmento para o topo.

    ; Neste ponto, movemo-nos para baixo independentemente de quaisquer
    ; cogumelos que possam bloquear o caminho do segmento. Qualquer coisa
    ; no caminho do segmento será obliterada.
    inc (ix+1)          ; ainda não chegou ao fundo, mover para baixo.
    ret

    ; mover segmento para o topo do ecrã.
    segmt: xor a         ; o mesmo que ld a,0, mas poupa 1 byte.
    ld (ix+1),a         ; nova coordenada x = topo do ecrã.
    ret

    ; Deteção de colisão do segmento.
    ; Verifica colisões com o jogador e com os projéteis do jogador.
    segcol: ld a,(ply)
    cp (ix+2)           ; é idêntica à coordenada y do segmento?
    jr nz,bulcol        ; se forem diferentes, verificar projétil.
    ld a,(plx)
    cp (ix+1)           ; é a mesma do segmento?
    jr nz,bulcol        ; se forem diferentes, verificar projétil.

    ; Se chegámos aqui, houve uma colisão com o jogador.
    killpl: ld (dead),a  ; definir flag para indicar que o jogador está morto.
    ret

    ; Vamos verificar a colisão com o projétil do jogador.
    bulcol: ld a,(pbx)   ; coordenada x do projétil.
    inc a               ; está no valor padrão?
    ret z               ; sim, não há projétil a verificar.
    cp (ix+1)           ; a coordenada x do projétil é igual à do segmento?
    ret nz              ; não, logo não há colisão.
    ld a,(pby)          ; posição y do projétil.
    cp (ix+2)           ; é idêntica à coordenada y do segmento?
    ret nz              ; não, logo não há colisão.

    ; Se chegámos aqui, houve colisão com o projétil do jogador.
    call dbull          ; apagar projétil.
    ld a,22             ; código AT.
    rst 16
    ld a,(pbx)          ; coordenada vertical do projétil do jogador.
    inc a               ; 1 linha abaixo.
    rst 16              ; definir posição vertical do cogumelo.
    ld a,(pby)          ; posição horizontal do projétil.
    rst 16              ; definir coordenada horizontal.
    ld a,16             ; código ASCII para controlo INK.
    rst 16
    ld a,4              ; 4 = cor verde.
    rst 16              ; queremos todos os cogumelos nesta cor!
    ld a,145            ; UDG 'B' é o gráfico do cogumelo.
    rst 16              ; colocar cogumelo no ecrã.
    call kilbul         ; desativar/matar o projétil.
    ld (ix),a           ; desativar/matar o segmento.
    ld hl,numseg        ; número de segmentos.
    dec (hl)            ; decrementar.
    ret

    ; Gerador simples de números pseudoaleatórios.
    ; Avança um ponteiro através da ROM (guardado em seed), retornando
    ; o conteúdo do byte nessa posição.
    random: ld hl,(seed)
    ld a,h
    and 31
    ld h,a              ; manter nos primeiros 8K da ROM.
    ld a,(hl)           ; obter número "aleatório" da posição.
    inc hl              ; incrementar ponteiro.
    ld (seed),hl
    ret
seed:
    defw 0              ; ponteiro

    ; Calcular endereço do atributo para o caráter em (dispx, dispy).
atadd:
    ld a,c              ; coordenada vertical.
    rrca
    rrca
    rrca                ; multiplicar por 32.
    ld e,a              ; Rodar para a direita com carry 3 vezes é
    and 3               ; mais rápido do que rodar para a esquerda 5 vezes.
    add a,88            ; 88x256=endereço dos atributos.
    ld d,a
    ld a,e
    and 224
    ld e,a
    ld a,b              ; posição horizontal.
    add a,e             ; de=endereço dos atributos.
    ld e,a
    ld a,(de)           ; retornar com atributo no acumulador.
    ret

    plx: defb 0          ; coordenada x do jogador.
    ply: defb 0          ; coordenada y do jogador.
    pbx: defb 0
    pby: defb 255
    dead: defb 255       ; coordenadas e flag do jogador/projétil.

    ; Gráficos UDG.
    blocks: defb 16,16,56,56,124,124,254,254  ; base do jogador.
    defb 24,126,255,255,60,60,60,60          ; cogumelo.
    defb 24,126,126,255,255,126,126,24        ; segmento.
    defb 0,102,102,102,102,102,102,0         ; projétil do jogador.

    ; Tabela de segmentos.
    segmnt: defb 0,0,0
    defb 0,0,0
    defb 0,0,0
    defb 0,0,0
    defb 0,0,0
    defb 0,0,0
    defb 0,0,0
    defb 0,0,0
    defb 0,0,0
    defb 0,0,0


    SAVESNA "7_prog7.sna", start
    SAVETAP "7_prog7.tap", CODE, "7_prog7", start, $ - start, start
```

Mas espere, por que razão existem dois testes de deteção de colisão em vez de apenas um? Bem, imagine que a base da arma do jogador está uma célula de caráter à esquerda de um segmento da centopeia. O jogador está a mover-se para a direita e o segmento está a mover-se para a esquerda. No fotograma (*frame*) seguinte, o segmento mover-se-ia para a célula ocupada pelo jogador, e o jogador mover-se-ia para a posição ocupada pelo segmento no fotograma anterior — o jogador e o segmento da centopeia passariam diretamente um pelo outro, e uma única verificação de deteção de colisão falharia em detetar isto. Ao verificar a colisão após o movimento do jogador, e depois novamente após o movimento dos segmentos da centopeia, conseguimos evitar este problema.

## Colisões Entre Sprites

Com certeza, a maioria dos jogos do Spectrum utiliza *sprites* em vez de UDGs, por isso no próximo capítulo veremos como os *sprites* podem ser desenhados. Para a deteção de colisões, o mesmo princípio de verificação de coordenadas pode ser usado para detetar colisões entre *sprites*. Subtraímos as coordenadas do primeiro *sprite* às do segundo, examinamos a diferença e, se esta estiver dentro do intervalo de tamanho dos dois *sprites* combinados, temos uma colisão nesse eixo. Uma verificação simples de colisão para dois *sprites* de 16x16 píxeis seria semelhante a isto:

```assembly
    DEVICE ZXSPECTRUM48
    ORG $8000

start:
    ; Verificar colisão de (l, h) com (c, b), aplicação estrita.
colx16:
    ld a,l              ; coordenada x.
    sub c               ; subtrair x.
    add a,15            ; adicionar distância máxima.
    cp 31               ; dentro do intervalo de x?
    ret nc              ; não - falhou.
    ld a,h              ; coordenada y.
    sub b               ; subtrair y.
    add a,15            ; adicionar distância máxima.
    cp 31               ; dentro do intervalo de y?
    ret                 ; flag de carry ativa se houver colisão.


    SAVESNA "7_prog8.sna", start
    SAVETAP "7_prog8.tap", CODE, "7_prog8", start, $ - start, start
```

Existe um inconveniente neste método. Se os seus *sprites* não preencherem totalmente os seus limites de 16x16 píxeis, a deteção de colisão parecerá demasiado rigorosa (estrita), e ocorrerão colisões quando os *sprites* estiverem próximos mas sem se tocarem realmente. Uma verificação ligeiramente menos sensível envolveria o corte dos cantos dos *sprites* num formato mais octogonal, especialmente se os seus *sprites* tiverem cantos arredondados. A rotina abaixo funciona somando as diferenças das coordenadas x e y e verificando se estas estão abaixo de um determinado limite. Para uma colisão entre dois *sprites* de 16x16, as distâncias máximas de coordenadas são de 15 píxeis para cada eixo, pelo que, ao verificar se a soma das diferenças de x e y é 25 ou menos, estamos efetivamente a cortar um triângulo de 5x5 píxeis em cada canto.

```assembly
    DEVICE ZXSPECTRUM48
    ORG $8000

start:
    ; Verificar colisão de (l, h) com (c, b), cortando cantos.
colc16:
    ld a,l              ; coordenada x.
    sub c               ; subtrair x.
    jr nc,colc1a        ; o resultado é positivo.
    neg                 ; tornar negativo em positivo.
    colc1a: cp 16        ; dentro do intervalo de x?
    ret nc              ; não - falhou.
    ld e,a              ; guardar a diferença.

    ld a,h              ; coordenada y.
    sub b               ; subtrair y.
    jr nc,colc1b        ; o resultado é positivo.
    neg                 ; tornar negativo em positivo.
    colc1b: cp 16        ; dentro do intervalo de y?
    ret nc              ; não - falhou.

    add a,e             ; adicionar diferença de x.
    cp 26               ; apenas 5 píxeis de canto a tocar?
    ret                 ; carry ativo se houver colisão.


    SAVESNA "7_prog9.sna", start
    SAVETAP "7_prog9.tap", CODE, "7_prog9", start, $ - start, start
```
