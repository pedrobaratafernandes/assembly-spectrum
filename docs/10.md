# Capítulo Dez - Pontuações e Pontuações Máximas

## Mais Rotinas de Pontuação

Até agora, temos utilizado uma rotina de pontuação pouco sofisticada. A nossa pontuação é mantida como um número de 16 bits guardado num par de registos e, para a mostrar, utilizámos a rotina de impressão/visualização de números de linha da ROM do Sinclair. Existem dois inconvenientes principais neste método: primeiro, estamos limitados a números de 0 a 9999; segundo, o aspeto visual é terrível.

Poderíamos converter nós próprios um número de 16 bits em ASCII da seguinte forma:

```assembly
    ; Mostrar o número passado em hl, alinhado à direita.
shwnum:
    ld a,48             ; zeros iniciais (ou 32 para espaços).
    ld de,10000
    call shwdg          ; mostrar dígito da casa das dezenas de milhar.
    ld de,1000
    call shwdg          ; mostrar dígito da casa dos milhares.
    ld de,100
    call shwdg          ; mostrar dígito da casa das centenas.
    ld de,10
    call shwdg          ; mostrar dígito da casa das dezenas.
    or 16               ; o último dígito é sempre mostrado.
    ld de,1
shwdg:
    and 48              ; limpar carry, limpar dígito.
shwdg1:
    sbc hl,de
    jr c,shwdg0         ; nada para mostrar.
    or 16               ; algo para mostrar, torná-lo um dígito.
    inc a               ; incrementar dígito.
    jr shwdg1           ; repetir até a coluna ser zero.
shwdg0:
    add hl,de           ; restaurar o total.
    push af
    rst 16              ; mostrar caráter.
    pop af
    ret
```

Este método funciona bem, embora continuemos limitados a uma pontuação de cinco dígitos não superior a 65535. Para uma apresentação mais profissional, completa com qualquer número de zeros iniciais, precisamos de manter a pontuação como uma string de dígitos ASCII.

Utilizo a mesma técnica de pontuação há cerca de 15 anos. Não é terrivelmente sofisticada, mas é boa o suficiente para o que precisamos. Este método utiliza um caráter ASCII por dígito, o que facilita a sua exibição. Por curiosidade, esta rotina foi retirada do jogo de tiros *More Tea, Vicar?*:

```assembly
score: defb '000000'

uscor:
    ld a,(hl)           ; valor atual do dígito.
    add a,b             ; adicionar pontos a este dígito.
    ld (hl),a           ; colocar o novo dígito de volta na string.
    cp 58               ; valor superior ao ASCII '9'?
    ret c               ; não - podemos descansar.
    sub 10              ; subtrair 10.
    ld (hl),a           ; colocar o novo caráter de volta na string.
uscor0:
    dec hl              ; caráter anterior na string.
    inc (hl)            ; incrementar este dígito em um.
    ld a,(hl)           ; qual é o novo valor?
    cp 58               ; ultrapassou o ASCII nove?
    ret c               ; não, pontuação processada.
    sub 10              ; subtrair dez.
    ld (hl),a           ; colocar de volta.
    jp uscor0           ; repetir o processo.
```

Para a utilizar, apontamos `HL` para o dígito que gostaríamos de incrementar, colocamos a quantidade a adicionar no registo `B` e chamamos `uscor`. Por exemplo, para adicionar 250 pontos à pontuação, são necessárias 6 linhas:

```assembly
    ; Adicionar 250 à pontuação.
    ld hl,score+3       ; apontar para a coluna das centenas.
    ld b,2              ; 2 centenas = 200.
    call uscor          ; incrementar a pontuação.
    ld hl,score+4       ; apontar para a coluna das dezenas.
    ld b,5              ; 5 dezenas = 50.
    call uscor          ; incrementar a pontuação.
```

Simples, mas faz o seu trabalho. Os mais puristas apontariam, sem dúvida, que isto poderia ser feito usando BCD (Binary Coded Decimal), e que todas as instruções para isso estão no conjunto de instruções do Z80.

Este programa junta as duas rotinas: mostra três números com `shwnum` e depois soma 250 pontos oito vezes a uma pontuação guardada como texto, mostrando-a de cada vez:

```assembly
        DEVICE ZXSPECTRUM48
        ORG 32768
start:
    ld a,2              ; ecrã superior.
    call 5633           ; abrir canal.
    ld hl,7             ; mostrar alguns números com shwnum.
    call numlin
    ld hl,1234
    call numlin
    ld hl,65535
    call numlin
    ld b,8              ; somar 250 pontos oito vezes.
pontos:
    push bc
    ld hl,score+3       ; apontar para a coluna das centenas.
    ld b,2              ; 2 centenas = 200.
    call uscor
    ld hl,score+4       ; apontar para a coluna das dezenas.
    ld b,5              ; 5 dezenas = 50.
    call uscor
    ld de,score         ; mostrar a pontuação (string de 6 dígitos).
    ld bc,6
    call 8252
    ld a,13             ; mudar de linha.
    rst 16
    pop bc
    djnz pontos
    ret

numlin:
    call shwnum         ; mostrar hl.
    ld a,13             ; mudar de linha.
    rst 16
    ret

    ; Mostrar o número passado em hl, alinhado à direita.
shwnum:
    ld a,48             ; zeros iniciais (ou 32 para espaços).
    ld de,10000
    call shwdg          ; mostrar dígito da casa das dezenas de milhar.
    ld de,1000
    call shwdg          ; mostrar dígito da casa dos milhares.
    ld de,100
    call shwdg          ; mostrar dígito da casa das centenas.
    ld de,10
    call shwdg          ; mostrar dígito da casa das dezenas.
    or 16               ; o último dígito é sempre mostrado.
    ld de,1
shwdg:
    and 48              ; limpar carry, limpar dígito.
shwdg1:
    sbc hl,de
    jr c,shwdg0         ; nada para mostrar.
    or 16               ; algo para mostrar, torná-lo um dígito.
    inc a               ; incrementar dígito.
    jr shwdg1           ; repetir até a coluna ser zero.
shwdg0:
    add hl,de           ; restaurar o total.
    push af
    rst 16              ; mostrar caráter.
    pop af
    ret

score: defb '000000'

uscor:
    ld a,(hl)           ; valor atual do dígito.
    add a,b             ; adicionar pontos a este dígito.
    ld (hl),a           ; colocar o novo dígito de volta na string.
    cp 58               ; valor superior ao ASCII '9'?
    ret c               ; não - podemos descansar.
    sub 10              ; subtrair 10.
    ld (hl),a           ; colocar o novo caráter de volta na string.
uscor0:
    dec hl              ; caráter anterior na string.
    inc (hl)            ; incrementar este dígito em um.
    ld a,(hl)           ; qual é o novo valor?
    cp 58               ; ultrapassou o ASCII nove?
    ret c               ; não, pontuação processada.
    sub 10              ; subtrair dez.
    ld (hl),a           ; colocar de volta.
    jp uscor0           ; repetir o processo.
fim:

; --- Carregador BASIC + ficheiro .tap (igual em todos os exemplos) ---
        ORG 23755
basic:  db 0,10                 ; 10 CLEAR 32767: LOAD "" CODE: RANDOMIZE USR 32768
        dw basic_fim-basic-4
        db $FD,$B0,'"32767":',$EF,'""',$AF,':',$F9,$C0,$B0,'"32768"',13
basic_fim:
        EMPTYTAP "cap10_1.tap"
        SAVETAP  "cap10_1.tap",BASIC,"cap10_1",basic,basic_fim-basic,10
        SAVETAP  "cap10_1.tap",CODE,"cap10_1",start,fim-start
```

## Tabelas de Pontuações Máximas

As rotinas de pontuações máximas (*high scores*) não são especialmente fáceis de escrever para um principiante, mas assim que escrever uma, poderá reutilizá-la vezes sem conta. O princípio básico é que começamos no fundo da tabela e subimos até encontrar uma pontuação que seja maior ou igual à pontuação do jogador. Em seguida, deslocamos todos os dados na tabela abaixo desse ponto uma posição para baixo e copiamos o nome e a pontuação do jogador para a tabela nessa posição.

Podemos definir o par de registos `HL` ou `IX` para o primeiro dígito da pontuação mais baixa na tabela e comparar cada dígito com o correspondente na pontuação do jogador. Se o dígito na pontuação do jogador for mais alto, subimos uma posição; se for mais baixo, paramos aí e copiamos a pontuação do jogador para a tabela uma posição abaixo. Se ambos os dígitos forem iguais, passamos para o dígito seguinte e repetimos a verificação até que os dígitos sejam diferentes ou tenhamos verificado todos os dígitos da pontuação. Se as pontuações forem idênticas, colocamos a entrada do jogador na tabela uma posição abaixo. Isto é repetido até que uma pontuação na tabela seja mais alta do que a pontuação do jogador, ou até chegarmos ao topo da tabela.

Ao inicializar uma tabela de pontuações máximas pela primeira vez, pode ser tentador colocar o seu próprio nome no topo com uma pontuação muito difícil de bater. Tente resistir a esta tentação. As tabelas de pontuações máximas servem para o jogador avaliar o seu próprio desempenho, e não faz sentido frustrar o jogador tornando a primeira posição quase impossível de alcançar.

## Notas

* Na rotina `shwnum`, o registo `a` guarda o carácter a mostrar. `and 48` reduz `a` a 48 (`'0'`) ou a 32 (espaço), conforme já se tenha mostrado ou não um algarismo diferente de zero, e `or 16` transforma um espaço em `'0'`. Começando com `ld a,48`, o número aparece com zeros à esquerda (`00007`); começando com `ld a,32`, aparece alinhado à direita com espaços (`    7`).
* Cada algarismo calcula-se subtraindo repetidamente a potência de 10 (`sbc hl,de`) até o resultado ficar negativo, e somando-a uma vez de volta (`add hl,de`). O número de subtrações é o algarismo.
* Na rotina `uscor`, cada carácter da pontuação é um algarismo ASCII de `'0'` (48) a `'9'` (57). Quando a soma passa de 57, subtrai-se 10 e soma-se 1 ao algarismo à esquerda, exatamente como no "e vai um" das contas de cabeça.
* A alternativa mencionada é o BCD (*Binary Coded Decimal*), em que cada metade de um byte guarda um algarismo de 0 a 9: o número 45 fica guardado como `$45`. Depois de um `add` ou `sub`, a instrução `daa` corrige o resultado para BCD (por exemplo, `$09 + $01` dá `$0A`, e `daa` transforma-o em `$10`).
